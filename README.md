# 🔓 Brute Force Password Cracker

A Python-based tool that demonstrates how **brute force attacks** work by systematically guessing a password through all possible combinations.

## 🚀 Features

- Simulates real brute-force password cracking
- Supports letters, numbers, and special characters
- Displays time taken, number of attempts, and password strength
- Great for ethical hacking and cybersecurity awareness

## 🧠 Purpose

This project helps users understand:
- How vulnerable weak passwords are
- The importance of strong password policies
- Basic cybersecurity attack simulation techniques

## 💻 Tech Stack

- Python
- Modules: `itertools`, `string`, `time`
